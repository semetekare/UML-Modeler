# Открытый курс по UML взамен пособия ВМК МГУ: что есть и что из этого можно взять

Дата: 2026-11-07. Проверено по первоисточникам (лицензия — на странице курса или в
метаданных репозитория), а не по пересказам поисковиков.

## 1. Задача

Текущее пособие — «Упражнения по UML-моделированию системы регистрации на курсы»
(ВМК МГУ, Малышко В. В., VP 16.3): 20 упражнений, 48 диаграмм, 5 типов диаграмм,
один сквозной пример. Права: «размещение на других ресурсах, а также коммерческое
использование — только с разрешения автора» (`docs/research/REFERENCE-CONTENT.md` §4.5).
Значит, ни текст, ни 54 снимка интерфейса в поставку не идут.

Нужен курс, который **разрешено копировать и перерабатывать** (перевод, сокращение,
переписывание шагов под наш редактор), а не просто «бесплатно читать».

## 4. Рекомендация

### Вариант A — если нужна коммерческая пригодность

Собирать курс из CC BY / CC BY-SA источников, а не искать «готовый русский курс»
(его нет: все русские пособия — издательский копирайт).

- **Ядро упражнений** — OER Informatik (CC BY 4.0): там уже есть то, чего нет в
  других местах, — задачи с решениями и баллами по каждому типу диаграмм.
- **Связная теория** — французский курс (CC BY 4.0): классы, последовательности,
  use cases, с TD.
- **Рамка «требования → эскиз → проект»** — блок UML у Saylor (CC BY 3.0).
- **Сквозной пример и упражнение по развёртыванию** — писать самим: открытого
  источника по deployment не нашлось, а свой текст принадлежит нам.

Покрытие 20 упражнений текущего курса:

| Текущие упражнения | Чем закрывается |
| --- | --- |
| 3.1–3.2 (use case) | набор OER «Übungen Use-Case» + французский курс |
| 3.3 (описания ВИ) | писать самим (шаблон описания — обычная практика, не охраняется) |
| 3.4 (activity) | набор OER «Übungen Aktivität» |
| 4.1 (class, логическое представление) | OER «Übungen Klassendiagramm» + французский курс |
| 4.2–4.4, 4.3.A/C (sequence) | OER «Sequenz-Übungen» + французский курс |
| 4.3.B, 5.2.F/G/H, 5.3 (class) | OER «Übungen Klassendiagramm» (продвинутые задачи) |
| 5.1 (deployment) | писать самим |
| 5.2.A–D (sequence, уточнение) | OER «Sequenz-Übungen» (продвинутые) |

Объём работы: перевод и переработка ~5 наборов задач (порядка 50 страниц) +
свои вводные и сквозной пример + 20 эталонных моделей в нашем редакторе. Это
меньше, чем кажется: решения уже есть, проверять логику не нужно — нужно
переписать под наш интерфейс и наш сквозной пример.

### Вариант B — если проект заведомо некоммерческий

Брать **iMooX** (CC BY-NC-SA 4.0): 6 уроков, 5 типов диаграмм, задачи с
решениями, видео, self-assessment — ближайший по педагогике аналог. Но: немецкий
→ русский, и весь переработанный курс обязан выйти под CC BY-NC-SA 4.0, а любая
коммерциализация (продажа, реклама, платная подписка) запрещена.

## 5. Если адаптировать: как оформить

На каждой странице курса — блок:

```
Основано на: <автор>, «<название>», <URL>.
Лицензия: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/.
Изменения: перевод на русский, сокращение, замена инструмента на <наш редактор>,
новые рисунки и эталонные модели.
```

Правила, которые нельзя терять:

1. **Атрибуция** — автор, название, ссылка, лицензия; для изменённого — отметка,
   что изменено (это требование CC BY, а не вежливость).
2. **ShareAlike** — если взяли BY-SA (Blueprints), производное распространяется
   под той же лицензией; смешивать с BY-материалами можно, но итог всё равно SA.
3. **NC** — «некоммерческое» относится к назначению использования, а не к наличию
   цены: реклама и платные функции тоже считаются коммерцией.
4. **Чужие материалы внутри** — у Saylor и OER Informatik часть картинок/текста
   может быть третьей стороны; проверять подвал каждой страницы, а не только
   общую лицензию сайта.
5. **Реестр источников** — таблица «упражнение → источник → что изменено»; без
   неё через полгода невозможно ни доказать права, ни обновить курс.

## 6. Открытые вопросы

1. Нужна ли коммерческая пригодность (продажа, реклама, подписка)? От этого
   зависит A или B.
2. Допустим ли ShareAlike для текста курса (BY-SA), или нужен строго BY?
3. Оставляем ли сквозной пример «регистрация на курсы» (он пришёл из учебной
   литературы и совпадает с чужим сюжетом) или придумываем свой домен?
4. Нужен ли deployment-раздел: своего источника нет, писать самим.
