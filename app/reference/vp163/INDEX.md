# Указатель рисунков учебника Visual Paradigm 16.3

Все 54 рисунка учебного пособия «Упражнения по UML-моделированию системы регистрации
на курсы в среде Visual Paradigm 16.3» (ВМК МГУ, Малышко В. В.), извлечённые из
HTML-версии пособия.

## Как устроены имена файлов

Исходные файлы в архиве пособия назывались `<номер>_ynOd.png`, где `<номер>` —
склеенный номер рисунка без точек: `3102_ynOd.png` = Рис. 3.1.2, `4306_ynOd.png` =
Рис. 4.3.6, `1001a_ynOd.png` = Рис. 1.1a. При переносе суффикс `_ynOd` отброшен,
номер сохранён: **`3102.png`, `4306.png`, `1001a.png`** и т. д. Соответствие
«номер рисунка → файл» однозначное и проверяется арифметически: убрать точки из
номера рисунка — получить имя файла.

Размеры снимков разные: это фрагменты окон и панелей, а не полные экраны.
Полное окно Visual Paradigm есть только на рис. 1.1 и 1.1a — оба **728 × 511 px**.
Масштаб изображения — **1:1** (следов пересэмплирования нет: 1-px линии остаются
ровно одной строкой одного значения, чёрный текст сохраняет ядро `(0,0,0)`).
Уменьшено не изображение, а **само окно**: полезная часть кадра — примерно
709 × 502 px, а не 1440 × 900, которые заявлены в `app/mechanics.json`. Отсюда
следствие для обмеров: абсолютные пиксели этого снимка нельзя выдавать за
размеры окна 1440 × 900. Разбор — `docs/MEASUREMENTS-AUDIT.md`.

> **Важно про диаграмму коммуникации.** В пособии она **не моделируется**: нет ни
> одного рисунка и ни одного упражнения с диаграммой коммуникации. Слово
> `Communication Diagram` встречается один раз — в настройках проекта
> (`Project Options -> Diagramming -> Show sequence number in Communication Diagram`),
> и ещё два раза в смысле «пути коммуникации» между узлами на диаграмме размещения.
> Кооперация (`Collaboration`) в пособии используется как контейнер модели
> (пакет `Login`, `RegisterForCourses`), а не как диаграмма.
