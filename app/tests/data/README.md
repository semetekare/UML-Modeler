# Данные тестов: копии фикстур и корпуса

Здесь лежат **копии** двух наборов проекта, нужные только тестам приложения:

| Папка | Откуда | Что |
|---|---|---|
| `rules/` | `tests/rules/` (корень проекта) | 32 фикстуры: 16 правил стандарта × пара «нарушение / контроль». Условия слоя практики лежат не здесь, а прямо в `tests/rules.mjs`: у советов нет фикстур, их границы калибруются по корпусу |
| `corpus/` | `tests/corpus/` (корень проекта) | 48 моделей учебного пособия и `MANIFEST.json`. Модели сохранены **без видов**: 0 фигур, 0 связей-видов — поэтому правила о диаграммах на них молчат (`hasAnyView` в `src/rules/practice.js`) |

Копия, а не ссылка, потому что тесты работают от корня `app/`: `tests/types.mjs`
поднимает сервер над этой папкой и читает данные по HTTP, а `tests/rules.mjs` —
с диска. Подняться на уровень выше сервер не может.

**Источник истины — файлы в корне проекта** (`tests/rules/`, `tests/corpus/`);
здесь копия на момент итерации. Если фикстуры там поменяются, скопируйте их
заново — набор правил и движок от этого не меняются.

`corpus/INDEX.json` — список 48 файлов корпуса в том порядке, в каком их читают
тесты (у `MANIFEST.json` нет списка файлов, а листинг каталога по HTTP не
отдаётся).
