# 21 Примитивные типы

> **UML 2.5.1** (formal/2017-12-05) · Раздел 21 · печатные стр. 677–678 · PDF стр. 719–720

## 21.1 Краткое описание

Пакет PrimitiveTypes — независимый пакет, определяющий набор многократно используемых примитивных типов, которые обычно применяются при определении метамоделей. Метамодель UML использует пакет PrimitiveTypes.

## 21.2 Семантика

**Таблица 21.1** Области значений примитивных типов

| Integer | Экземпляр Integer — значение из (бесконечного) множества целых чисел (…-2, -1, 0, 1, 2…). |
| --- | --- |
| Boolean | Экземпляр Boolean — одно из предопределённых значений true и false. |
| String | Экземпляр String определяет последовательность символов. Наборы символов могут включать нелатинские алфавиты. Семантика самой строки зависит от её назначения; это может быть комментарий, выражение вычислительного языка, выражение OCL и т. д. |
| UnlimitedNatural | Экземпляр UnlimitedNatural — значение из (бесконечного) множества натуральных чисел (0, 1, 2…) плюс неограниченно. Значение «неограниченно» показывается звёздочкой (‘*’). Значения UnlimitedNatural обычно используются для обозначения верхней границы диапазона, например кратности; неограниченно используется всегда, когда диапазон задан как не имеющий верхней границы. |
| Real | Экземпляр Real — значение из (бесконечного) множества вещественных чисел. Как правило, реализация внутренне представляет вещественные числа по стандарту плавающей точки, например ISO/IEC/IEEE 60559:2011 (содержание которого идентично предшествующему стандарту IEEE 754). |
